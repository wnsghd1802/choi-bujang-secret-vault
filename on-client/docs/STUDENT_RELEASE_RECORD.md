### 2-3. 패키지·실행 명령과 브라우저 결과

`on-client/package.json`의 `start`·`demo`·`check`는 각각 `node src/server.mjs`, `node src/server.mjs --demo`, `node --check student/extension.mjs`입니다. `on-client` 하위에는 `package-lock.json`이 없고 dependencies/devDependencies 선언이 없습니다. 최상위의 별도 `package-lock.json`은 기존 1~12단계 프로젝트용입니다. 새 복제 폴더에서 임의의 `npm install`이나 외부 패키지 설치를 실행하지 않았습니다.

학생이 실제 실행하여 오류 없는 출력을 제출한 문법 검사:

```powershell
npm.cmd --prefix "<새 복제 폴더>\on-client" run check
```

**관찰:**
```text
> alekov-client-starter@0.2.11 check
> node --check student/extension.mjs
```

정적 문법 검사가 종료됐음을 보여 주지만, 전체 통합 테스트·실시간 보안 접속·실행 권한 검증을 대신하지 않습니다.

새 복제 폴더에서 안내한 실행 명령(기존 5189와 충돌하지 않도록 다른 포트 사용):


**브라우저 재현:** 학생은 이 안내에 따라 보호 현황·업무 앱·보안 기록·패키지 조회 화면의 실제 캡처를 전달했습니다. 세 메뉴에서 학생 표시 함수가 호출되어 결과를 표기하는 화면을 확인했습니다. 다만 캡처에 **브라우저 주소 표시줄이나 새 서버 PowerShell의 시작 출력이 포함되지 않아**, 해당 브라우저 세션의 실제 포트(5190)를 캡처만으로 독립 확인한 증거는 없습니다. 화면 재현 관찰과 포트 증거를 구분합니다.

**실제 서버 상태:** 보안 엔진은 `disconnected`로 표시되며, 로그인·앱 목록·기기·세션·XDR 기록 요청은 기존 서버/에이전트 연결 오류를 보였습니다. 이는 **기능적 연결 성공이나 실데이터 재현이 아니라 ‘연결 없음’ 상태의 화면 재현**입니다.

**실제 패키지 조회의 증거:**


조회 시각 `2026-10-27 16:01:39 KST`. `https://api.osv.dev/v1/querybatch`는 **출처 표시 주소**이며, 이 결과만으로 OSV 네트워크 조회 발생을 증명하지 않습니다. `not_configured`는 취약점이 없다는 뜻이 아닙니다.

**종료 및 재실행:** 제공 스크립트는 `Ctrl+C` 종료와 같은 명령으로 재실행하는 절차를 지원하지만 **사용자가 종료 화면과 같은 커밋의 재실행 결과를 제출하지 않아 미확인**입니다. ‘했다고 가정’하라는 요청은 문서의 실행 관찰로 변환하지 않았습니다.

## 4. 이동 가능한 구성·실행 진입점

문서의 고정된 사용자 홈 절대 경로는 **증거를 설명하기 위한 기록**이고 필수 실행 위치가 아닙니다. 설치 환경에 맞춰 다른 빈 디렉터리를 지정할 수 있습니다. 코드에서 실행 폴더는 `start-alekov.ps1`의 `$PSScriptRoot` 부모와 `src/server.mjs`의 모듈 상대 경로로 결정됩니다. 비밀 설정값이나 기존 로컬 Windows SID를 Git 복제로 옮기지 않습니다.

공개 GitHub 저장소에서 기본 화면을 재현하는 절차(Windows PowerShell; 값은 예시로 치환):

```powershell
git clone --branch main --single-branch https://github.com/wnsghd1802/choi-bujang-secret-vault.git "<새 빈 폴더>"
git -C "<새 폴더>" rev-parse HEAD
npm.cmd --prefix "<새 폴더>\on-client" run check
powershell -NoProfile -ExecutionPolicy Bypass -File "<새 폴더>\on-client\tools\start-alekov.ps1" -Port 5190
```

예시의 `<새 빈 폴더>`는 반드시 **실제 로컬 경로로 바꿔서** 사용합니다. 표준 포트 `5189`가 비어 있다면 문서 [STUDENT_RUNBOOK.md](STUDENT_RUNBOOK.md)의 기본 명령을 그대로 사용합니다. 브라우저에서 포트를 맞춰 열고, 실행 창 `Ctrl+C`로 종료한 뒤 필요시 같은 실행 명령을 재입력합니다. **이 절차 중 새 복제 폴더의 종료·재실행은 문서상 절차이며 이번 실제 시험 결과는 아닙니다.**

- 일반 초기 화면: Native Host·SDP 설정 없이 실행 가능하나 실제 접근 판정과 계정 연결은 `disconnected`로 남을 수 있습니다.
- `-NativeHostConfig`: 담당자가 승인한 별도 보호 파일이 있는 경우에만 지정합니다. 기존 폴더의 `native.json`과 보관함/레지스트리를 새 환경에 단순 복사하지 않습니다.
- `-SdpHostConfig`: 운영자 제공 전용 파일과 CA/인증서/키/토큰 등이 필요합니다. Git·문서·메신저·재현 폴더로 옮기지 않습니다.
- OSV: `src/vulnerabilities/project-scan.mjs`는 운영자 승인된 공개 패키지와 검증된 `package-lock.json`/설치 메타데이터가 필요합니다. `ON_PROJECT_DIRECTORY`가 지정되지 않으면 `not_configured`가 정상적인 미조회 상태입니다.
- 학생 앱 `on-client`은 외부 npm dependencies/devDependencies를 선언하지 않으므로 앱 실행을 위해 최상위 `npm install`을 선행하지 않습니다. 다른 OS와 PowerShell 이외 환경은 미검증입니다.
- 제공 실행기의 옵션·오류는 `on-client/tools/start-alekov.ps1`, 학생 함수는 `on-client/student/extension.mjs`, API는 `on-client/src/server.mjs`를 기준으로 대조했습니다.

## 7. 제출 커밋과 학생 진술의 일치 확인

이 문서를 포함해 커밋한 후, GitHub의 제출할 40자리 커밋 SHA와 `main` HEAD를 확인합니다. `student/extension.mjs`·`public/app.js`·`src/server.mjs`·`on-client/package.json`은 독립 복제한 기준 커밋 대비 **변경이 없는지** 확인합니다. 이 문서가 추가됐다는 이유만으로 같은 최종 커밋에서 종료·재실행, AI 응답, 조치 집행까지 테스트했다고 간주하지 않습니다.

**22단계 제출:** ALEPH 과제 화면에서 저장소 URL과 **최종 문서 커밋 SHA**를 직접 입력합니다. 21·22단계에는 Workbench의 기존 13~20단계용 「포털 제출 준비」를 쓰지 않습니다. 공개 GitHub 저장소이므로 비공개용 원문 JSON 전달은 필요하지 않습니다. 원문 검토·서버 판정과 실제 학생 PC 실행은 별개입니다.

**학생 진술:** “별도 폴더에서 21단계 커밋을 Git 복제했고 문법 검사 및 연결 없음/프로젝트 미설정 상태의 주요 학생 화면 표시를 재현했다. 실제 SDP·AI 모델·조치 집행·OSV 검색·종료 후 재실행 및 최종 문서 커밋 자체의 전체 재현은 확인하지 않았다. 원본 작업물과 비밀 설정은 복제하지 않았다.”
